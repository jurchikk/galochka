# Галочка — список задач онлайн

Тестовое задание «Список задач (To-Do List)». Сделано как маленький продукт из двух страниц:

- **главная** — лендинг под поисковый запрос «список задач онлайн» с рабочим списком прямо на первом экране;
- **список задач** (`/doska/`) — отдельная рабочая страница, на неё ведут все кнопки главной.

Рабочий сайт: https://jurchikk.github.io/galochka/
Список задач: https://jurchikk.github.io/galochka/doska/

## Что сделано по заданию

| Требование | Как сделано |
|---|---|
| Добавление задач | Поле ввода, клавиша Enter или кнопка «Добавить». Пустую строку добавить нельзя. |
| Отметка выполненных | Кружок слева: задача зачёркивается, повторное нажатие возвращает её в работу. |
| Удаление задач | Крестик справа. Шесть секунд после удаления задачу можно вернуть кнопкой «Вернуть». |
| Сохранение после обновления | Список хранится в `localStorage` браузера и переживает обновление страницы и перезапуск браузера. |

## Что добавлено сверх задания

- правка задачи: кнопка с карандашом или двойной щелчок по тексту, Enter сохраняет, Esc отменяет;
- фильтр «Все / Активные / Выполненные», счётчик оставшихся задач, кнопка «Удалить выполненные»;
- светлая и тёмная тема: по умолчанию как на устройстве, переключается кнопкой;
- список на главной и на рабочей странице — один и тот же: задачи, добавленные на главной, уже лежат в полном списке, две открытые вкладки обновляются сами;
- при первом визите в списке три задачи-подсказки; если их удалить, они не возвращаются;
- вёрстка под телефон, управление с клавиатуры, подписи для программ чтения с экрана.

## Как устроено

Чистые HTML, CSS и JavaScript: без сборки, без библиотек, без внешних шрифтов и счётчиков. Сайт не делает ни одного запроса на чужие серверы и не ставит cookie.

```
index.html              главная (лендинг)
doska/index.html        рабочий список задач
404.html                страница «не найдено»
assets/css/styles.css   общие стили, светлая и тёмная тема
assets/js/store.js      логика списка без обращения к странице
assets/js/todo-ui.js    отрисовка списка (общая для обеих страниц)
assets/js/theme.js      переключатель темы
assets/js/board.js      запуск рабочего списка
assets/js/landing.js    запуск списка на главной
assets/img/             иконки и картинка для соцсетей
tests/store.test.js     тесты логики
tools/                  служебные скрипты (адрес сайта, картинки)
robots.txt, sitemap.xml, llms.txt, manifest.webmanifest, favicon.svg
site.config.json        текущий адрес сайта
```

Решения, которые стоит знать:

- **Логика отделена от страницы.** `store.js` не трогает DOM и не меняет исходный массив, поэтому проверяется обычными тестами.
- **Текст задачи нельзя превратить в код.** Он попадает на страницу только через `textContent`: задача `<b>текст</b>` показывается как текст.
- **Данные из хранилища проверяются при чтении.** Битая запись не ломает страницу, а даёт пустой список.
- **Если браузер не даёт сохранить** (приватный режим, нет места), человек видит сообщение, а не молча теряет задачи.
- **Страница не прыгает при загрузке.** Три задачи-подсказки стоят в разметке главной заранее, скрипт их подменяет.

## SEO главной страницы

- Основной запрос — «список задач онлайн». Дополнительные: «список дел онлайн», «без регистрации», «бесплатно», «to-do list онлайн», «туду-лист», «список дел на день», «как составить список дел». Частотность запросов инструментами не проверялась: ключи подобраны по смыслу.
- Один `h1`, семь разделов с `h2` под отдельные вопросы: что умеет, как пользоваться, где хранятся задачи, кому подойдёт и кому нет, как составить список дел на день, частые вопросы.
- В первом абзаце — определение сервиса одной фразой, которую можно процитировать отдельно от страницы. Ответы в разделе вопросов тоже называют сервис и понятны без контекста.
- Разметка schema.org: `WebSite`, `WebPage`, `WebApplication`, `FAQPage`, связанные между собой. Текст вопросов и ответов в разметке совпадает с текстом на странице слово в слово.
- Рабочий список закрыт от индексации (`noindex, follow`) и не входит в `sitemap.xml`: в поиске должна показываться главная, а не две страницы на один запрос.
- Кнопки называются «Открыть список задач», а не «доска»: слово «доска задач» в поиске означает канбан-доску, которой здесь нет.
- На странице нет выдуманных цифр, отзывов и оценок. Ограничения сервиса (нет синхронизации, напоминаний и общего доступа, список можно потерять при очистке данных браузера) названы прямо.
- Весь текст и ссылки есть в исходном HTML. Внешних ссылок нет.

Ограничение площадки: на GitHub Pages сайт проекта лежит в подпапке (`имя.github.io/galochka/`), а поисковики читают `robots.txt` только из корня домена. Поэтому `sitemap.xml` нужно добавить в Google Search Console и Яндекс Вебмастер вручную. На своём домене файл заработает как обычно.

## Как запустить у себя

Нужен любой статический сервер: модули JavaScript не работают при открытии файла двойным щелчком.

```bash
python -m http.server 8770
```

После этого сайт откроется по адресу http://localhost:8770/.

Тесты (нужен Node.js 20 или новее):

```bash
npm test
```

После публикации на новом адресе его нужно один раз прописать в canonical, разметке, `sitemap.xml`, `robots.txt`, `llms.txt` и этом файле:

```bash
node tools/set-site-url.mjs https://имя.github.io/galochka/
```

## Как проверялось

- 12 автоматических тестов логики: добавление, отметка, удаление и возврат, правка, фильтр, счётчик со склонением, сохранение и чтение, битые данные, недоступное хранилище.
- Вручную в браузере: добавление с клавиатуры и кнопкой, пустой ввод, задача с HTML-тегами, отметка, удаление и возврат, правка и отмена правки, все три фильтра, очистка выполненных и возврат, сохранение после обновления страницы и при переходе с главной в полный список.
- Экран телефона 375 px и экран компьютера 1280 px, светлая и тёмная тема: горизонтальной прокрутки и ошибок в консоли нет.
- Сдвиг вёрстки при загрузке главной (CLS) на локальном сервере — 0.
- Скриптом: разметка schema.org разбирается без ошибок, вопросы и ответы в ней совпадают с видимыми.
